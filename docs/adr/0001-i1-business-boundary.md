# ADR 0001 — I1 HTTP 业务闭环

状态：2026-11-11 用户确认，分支 feat/i1。

依据：需求文档、技术方案、研发计划及本会话确认的接口与验收范围。
I1 实现会话登录/退出、租户与角色、订单/政策查询、资格评估、动作确认、申请/取消、审批、
审计和周期过期扫描；不执行支付，不增加 MCP 业务工具或前端。

- 使用服务端持久会话（随机 token 的 SHA-256 摘要入库），HttpOnly Cookie，写请求 CSRF。
  登录标识使用现有 users.id，密码独立存储为 scrypt 摘要；无默认密码。显式提供 tenant_id
  仅用于登录选择成员关系，不授予权限。会话 8 小时，确认凭据 5 分钟。
- 支付时间未来无资格；恰好支付满 168 小时可申请。当前时间 >= approve_by/start_by 过期。
  仅申请人可取消 pending。角色和用户 enabled 在每次认证时重新读取。
- 批准事务原子写入决定、状态、30 分钟期限、唯一 execute 任务、审计。I1 不领取该任务。
- 所有写用例通过 UoW 提交。请求相关写锁按订单→申请顺序；幂等键提前加事务锁；
  同订单并发以订单锁和已有部分唯一索引兜底。禁止持锁调用外部网络。
- 创建/取消需一次性确认，与实际写入同事务消费。相同幂等键不同参数冲突；合法重试先返回原引用。
- 当前政策不可修改，申请记录不可变政策版本。当前实现只支持已确认的 168h/24h/30min/CNY
  全额未发货主管审批规则，不支持的政策配置拒绝使用。
- 只增加 0003 迁移，不改 0001/0002/schema.sql。新增 credentials、sessions、security_events；
  既有 orders/退款/审计数据保留。接管命令仍只负责 0002，随后 upgrade head 到 0003。
- 只在临时 PostgreSQL 核对并迁移验证；未获得远端连接配置，不推断 Lightsail 真实状态。

权限：support/supervisor/auditor 都可只读订单、政策、申请和审计；仅 support 创建/取消自己的申请；
仅 supervisor 审批，申请人即使有 supervisor 角色也不可自审。HTTP/MCP 共用应用服务。
使用稳定业务错误码，跨租户资源和不存在资源统一 404。安全事件在失败业务事务之外持久化。
